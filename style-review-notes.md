# Style Review Feedback

## Key Issues to Address:
1. **Brand identity** - "Portfolio" is too generic. Need a named personal/studio wordmark.
2. **Layout asymmetry** - Homepage sections too evenly stacked, case studies too repetitive with icon->heading->paragraph. Need stronger editorial imbalance.
3. **Typography contrast** - Space Grotesk needs bolder display moments, more decisive section titles, stronger contrast.
4. **Signature motifs** - Dot grids, mono labels, section numbers should be more intentional. Use fewer motif types consistently.
5. **Case study imagery** - Galleries repeat same device image. Need visual variety: closeups, diagrams, metrics, process artifacts.

## Style Decisions to Append to ideas.md:
- Brand identity: named personal/studio wordmark paired with geometric steel-blue monogram; "Portfolio" alone is not acceptable
- Layout rule: every major page must include at least one clearly asymmetric editorial composition
- Case-study imagery rule: galleries must show varied evidence of the work
